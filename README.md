# 📄 OCS Process and Resolution Automation System

## Description

This project aims to develop an intelligent system for the **Superior Collegiate Body (OCS - Órgano Colegiado Superior)** of the Instituto Superior Tecnológico Yaruquí, capable of:

- Capturing and consolidating all communications (emails, internal messages, external documents).
- Automatically classifying process types: credit transfer (homologation), graduation (titulación), course exemption (convalidación), appeals, scholarships, among others.
- Making decisions based on the received information:
  - Automatically requesting additional information.
  - Notifying internal departments according to the workflow.
  - Generating automatic resolutions whenever possible.
  - Flagging cases for manual review only in critical situations.
- Maintaining a complete history of each process for **traceability and auditing**.

---

## 🚀 Initial Features

- Automatic classification of communications by process type.
- Key information extraction using **NLP** and OCR depending on the document source.
- Decision engine with action workflows based on information status.
- Automatic notifications to students or internal departments.
- Generation of standardized resolutions in PDF/Word format.
- Consolidation of all information into a **single digital file per student/process**.
